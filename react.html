React adalah library JavaScript untuk membangun antarmuka pengguna (UI). Berbasis komponen, menggunakan JSX, dan virtual DOM untuk performa.

Contoh komponen sederhana:

function Welcome() {
  return <h1>Halo, React!</h1>;
}
